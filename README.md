# Карточка товара Teaboom

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка для просмотра не требуются.

## Сборка стилей

Для изменения SCSS установите Node.js и выполните в папке проекта:

```sh
npm ci
npm run build
```

Для автоматической пересборки стилей при изменениях:

```sh
npm run watch
```
